Introduction — the drift is the default #

Diagrams are drawn at design time and rot on the next merge. New joiners grep for weeks. Reviews miss coupling.

GlassMarble is a compiler + database + visualizer + agent that stays current via Git-aware incremental analysis (git diff HEAD → delta merge, idempotent). No server, no account — just .glassmarble/akg.json.

What you get #

🎨 31 living diagrams

14 UML + 7 C4 + 4 specialized + 6 analysis → Mermaid / PlantUML / DOT. global · folder: · file: scopes.

🛡️ Governance

hotspot · dependency · drift · compare · cycles, coupling, Instability. Snapshots + timeline track every SERVICE_ADDED … CYCLE_RESOLVED.

🧠 Grounded AI

BYOK, 10 providers, streaming, 32 tools that read the live AKG. Keys are 0600 and never logged. No hallucinated architecture.

⚡ Bounded & safe

MVCC + db.lock + tmp→fsync→rename→verify. Self-healing .bak. Snapshot caps at 15k nodes / 8 MB.

How it works — 60 seconds #

Multi-language source → Ingest (tree-sitter) → GAST normalization → Aggregate (topology & visibility) → Link (CPG + CFG/DFG + traits) → AKG (akg.json · GraphJSON v3 · MVCC) → Visualization (virtual subgraph → layout → M/P/D) → AI Architect (32 tools · BYOK) → Governance (hotspot · drift · compare)

Pipeline in 4 phases: ingest → normalize → aggregate → link → commit. File-by-file map and algorithms → Architecture → Pipeline. Storage contract (<100 MB @ 500k LOC) → AKG Format → Storage.

When to use — and when not to #

Great for: onboarding, PR reviews (compare + diff comment), architecture reviews (hotspot, drift), living docs (commit marbles/ in CI), grounded Q&A.

Not for: runtime profiling, dynamic tracing, or style linting — static analysis only (confidence < 1.0 for heuristics).

Verify a release #

Installers verify checksums.txt (SHA256) automatically. For hardening, verify Sigstore Cosign + SLSA provenance & SBOM (Syft/SPDX) attached per release.

# pin VERSION=v1.0.0; ARCH=linux_amd64
curl -fsSLO "https://github.com/Syamchand123/GlassMarble/releases/download/${VERSION}/gmb_${VERSION#v}_${ARCH}.tar.gz"
curl -fsSLO "https://github.com/Syamchand123/GlassMarble/releases/download/${VERSION}/checksums.txt"{,.pem,.sig}
sha256sum -c --ignore-missing checksums.txt
cosign verify-blob --certificate-identity-regexp "https://github.com/Syamchand123/GlassMarble/.github/workflows/release.yml@refs/tags/${VERSION}" --certificate-oidc-issuer https://token.actions.githubusercontent.com --signature checksums.txt.sig --certificate checksums.txt.pem checksums.txt

Architecture — executive summary #

GlassMarble resolves drift by treating the codebase as the single source of truth. 17 languages (14 with tree-sitter grammars — Go, Python, JS, TS, C, C++, C#, Java, Ruby, PHP, Rust, HTML/CSS/JSON + decl-only Kotlin/Swift/Scala) are compiled into a CPG, then committed as a portable GraphJSON AKG under .glassmarble/akg.json, and projected into 31 notations via Mermaid / PlantUML / DOT.

Multi-language code → [Ingestion: tree-sitter + GAST] → CPG (AST+CFG+DFG+Call Graph) → [Aggregation & Linking: topology + semantic binding] → AKG (GraphJSON v3) → [Virtual subgraph extraction] → Visualization (31 types) → Mermaid/PlantUML/DOT

Code Property Graph #

  • AST — types, interfaces, params, fields, expressions
  • CFG — branches, loops, exits, chronological execution
  • DFG — assignments, data propagation
  • Call Graph — static linkage, polymorphic bindings, concurrency threads

Architecture Knowledge Graph #

{"schema_version":3,"commit_hash":"f438841…","version":5,"entrypoints":["cmd.analyze.init"],"nodes":[{"id":"auth/login.go::Authenticator::Authenticate","kind":"FUNCTION","primitive":"NETWORK_IO","file_spec":{"path":"auth/login.go","line_start":18}}],"edges":[{"source_id":"…","target_id":"…","type":"CALLS","line_number":22,"confidence":1.0}]}

Deterministic, sorted, diff-friendly. GraphJSON v3 is the store; GraphJSON is the source of truth. Full schema → AKG Format.

GAST #

A GASTNode represents declarations, calls, scopes, fields uniformly across all 17 languages — decoupling the compiler from syntax.

Pipeline & algorithms #

  1. Ingest — multi-threaded tree-sitter walk, RichToken with structural flags
  2. Normalize — tokens → GAST, receiver call mapping, import resolution
  3. Aggregate — file → package clustering, visibility / FQN keys
  4. Link — call/interface/CFG/DFG/concurrency/primitive traits → final CPG → atomic commit

Resolution tricks: case-insensitive receivers, selector-path deconstruction, duck-typed interfaces, package-path stripping. Edge taxonomy → Relationship Types.

System diagram #

gmb CLI (28 commands) → internal/app pipeline → { code_analysis_engine (CPG) | visualization_engine (31 types) } → internal/akg (GraphJSON v3 + db.lock) → { arch_intelligence (patterns/stats) | arch_timeline + memory (snapshots/intelligence) }

Limitations #

  • 14 full grammars; Kotlin/Swift/Scala decl-only (no intra-CFG/DFG). JSON = config.
  • Static only — no runtime; dynamic calls ≈ (confidence < 1.0).
  • Graph store is GraphJSON v3; Turtle/RDF not shipped.
  • aging/fusion/learning/evolution are pipeline phases, not standalone CLI commands.

TUI vs plain / JSON #

TTY on both stdin & stdout → interactive Bubble Tea where available (analyze, tree, inspect, ai chat). Piped / --json → plain text, never interactive. Design intent: TUI for humans, plain/JSON for CI — byte-stable.

gmb analyze #

The workhorse: 4-phase pipeline → atomic GraphJSON commit → (with --intelligence default) intelligence → snapshots → memory.

gmb analyze [--full] [--commit <hash>] [--workers <n>] [--link-level architecture|standard|full] [--include-docs] [--bench] [--json]
  • Incremental delta is the default (git diff HEAD). --full forces full scan at full detail.
  • --bench verifies budgets: analyze ≤120s, commit ≤80s, state ≤50MB — exit 4 on failure.
  • Output: Analyzed 3 files | 120 nodes | 240 edges | … | state=180KB | 0.4s

gmb visualize #

gmb visualize <type> [--format mermaid|plantuml|dot] [--scope global|folder:<path>|file:<path>] [--entry <id>] [--depth 7] [--save <name>] [--render .svg]

31 types in 4 families — see Diagrams → Catalog. Scopes: whole graph, a folder, or a single file. gmb visualize list shows all 31; check validates.

AKG — GraphJSON shape #

{"schema_version":3,"commit_hash":"f438841…","version":5,"entrypoints":["cmd.analyze.init","main.main"],"nodes":[…],"edges":[…],"summary":{"primary_patterns":["…"]},"errors":[],"verified":true}

Single source of truth: .glassmarble/akg.json. Sorted, verified, diff-friendly. No WAL — one atomic file.

Nodes #

{"id":"auth/login.go::Authenticator::Authenticate","kind":"FUNCTION","name":"Authenticate","primitive":"NETWORK_IO","file_spec":{"path":"auth/login.go","line_start":18,"line_end":45},"properties":{"fully_qualified_name":"auth.Authenticator.Authenticate","module_name":"auth.login","return_type":"string"}}

IDs: <path>::<type>::<member> with ::param:/::field: suffixes. Kinds: PARAM, FUNCTION, STRUCT, INTERFACE, MODULE, ALIAS, … — schema v3 folds legacy TYPE_DECL→STRUCT.

Edges & predicates #

{"source_id":"auth/login.go::Authenticator::Authenticate","target_id":"db/database.go::DBStore::GetUser","type":"CALLS","line_number":22,"confidence":1.0}
PredicateMeaning
CALLSCall to function/method
BELONGS_TOMember → container
HAS_PARAM / HAS_FIELDFunction → param / Type → field
IMPLEMENTS / EXTENDSInterface / inheritance
DEPENDS_ONModule / package dependency
HAS_RECEIVERMethod → receiver type

Full 4-family taxonomy → Relationship Types: STRUCTURAL / BEHAVIORAL / DYNAMIC / SECURITY.

Storage contract #

--max-json-mb (global flag, 0=unlimited) gates akg.json. gmb status reports size; gmb stats --bench verifies budgets.

Nodesakg.json prettycompact30 snaps (no-graph)Total est.
13k (this repo)17 MB~12 MB~0.3 MB~30 MB
40k~52 MB~36 MB~0.9 MB~75 MB
67k (500k LOC)~88 MB~60 MB~1.5 MB~120 MB → set snapshot_no_graph:true

Keep <100 MB at 500k LOC: compact (~60 MB) dominates; rest via snapshot_no_graph + snapshot_max_count:30 + compact memory. Gate CI with --max-json-mb 100.

Configuration — precedence #

drift: #

drift:
  layers:
    - name: api
      paths: ["cmd/**", "internal/app/**"]
    - name: internal
      paths: ["internal/**"]
  forbidden_deps:
    - source: internal
      target: api

Agent loop #

You: "which services depend on payments?"
AI → LLM: system prompt + repo header (commit, nodes/edges, patterns)
LLM → AI: tool_call akg_traverse
AI → AKG: JSON facts
AI → LLM: tool results

Streaming #

On by default (stream:true). Tokens print as they arrive; fall back to one-shot JSON if the endpoint ignores it. Disable with --no-stream / GLASSMARBLE_AI_STREAM=0.

Sessions #

gmb ai chat  # resume latest
gmb ai chat --new
gmb ai sessions  # list, newest first
gmb ai sessions --delete <id>

Saved under .glassmarble/ai/sessions/ (0600), trimmed to max_session_messages at turn boundaries. exit/quit/bye or Ctrl+D to leave; summary prints tokens & cost.
